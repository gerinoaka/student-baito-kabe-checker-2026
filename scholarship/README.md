- 公開URL: https://gerinoaka.github.io/student-baito-kabe-checker-2026/scholarship/（親サイト「student-baito-kabe-checker-2026」のサブフォルダ。1サイトの1ページ）

## 4. PR リンクの設定（links-config.js）
- `url: ''` の行（40行目・47行目・54行目。それぞれ kakeibo / fp / tsushin）に、ASP で承認された https:// のリンクを貼る。空のままのカードは表示されない。冒頭コメントの行数を変えると行番号がずれるため、変えない。
- 3キーの意味と表示条件（最大2枠。上から kakeibo → fp → tsushin）:
  - `kakeibo`: 年齢が「18歳未満」でなければ表示（年齢未選択でも表示）
  - `fp`: 「18歳以上」を選び、第二種を含む場合、または毎月の返還額が2万円以上の場合
  - `tsushin`: 「18歳以上」を選んだ場合（空き枠の代わり）
- 借入を勧める案件（カードローン・奨学金の借換え・返済代行など）は貼らない。
- 広告コード（AdSense 等）を入れる場合は、`index.html` の `AD-SLOT-1` の div の `hidden` を外して中に貼る。
- AdSense やアクセス解析を追加するときは、プライバシーポリシーの「広告カードの表示時の計測用画像を除き、本ページはCookieや解析ツールを使いません」も必ず更新する。

## 5. 計算仕様の要約
- 返還年数: 貸与総額を算出表（全16区分）の基準額で割り、小数点以下を切り捨てる。3,400,001円以上は20年。返還回数（月賦）は年数×12。第二種にも同じ表を使う（JASSOの返還例で再現できることを確認済み。明文は未確認）。
- 第一種: 月額 = floor(総額 ÷ 回数)。総返還額 = 総額。最終回の調整は「目安」として注記。
- 第二種: 元利均等・月利 = 年利 ÷ 12 の標準式。月額は四捨五入、総返還額 = 月額 × 回数。補正係数は入れない（「目安」バッジと注記を常時表示）。テストで「JASSOの返還例より0.3〜1.5%低い」ことを固定しており、数式を JASSO の値に合わせる改変を検出する。
- 併用: 合算した総額で返還年数を決め、第一種・第二種をそれぞれの元本で計算して月額を足す（解釈。月賦・半年賦の配分は計算しない）。
- 完済月 = 貸与終了月 + (回数 + 6) か月（初回は貸与終了の翌月から数えて7か月目、最終回は初回の(回数−1)か月後）。年齢は月単位。
- 逆算モード: 第一種は ceil(総額 ÷ 月額)、第二種は対数式で切り上げ。月額が月の利息以下なら完済できない（noPay）、600回（50年）超は計算しない（tooLong）。併用は1〜600回で最小の回数を探す。
- 短くする（早く返す場合の目安）: 年数を1〜標準年数で指定できる。標準より長くはできず、標準に丸める。繰上返還の制度名・条件は確認していないため、画面では断定しない。
